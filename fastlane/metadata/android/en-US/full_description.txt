Shows and records USB video class (UVC) cameras, like webcams and video capture devices.

* Automatic camera configuration, with manual settings as a fallback
* Support for MJPEG and YUY2 cameras
* MP4 recording (H.264 or HEVC) with the phone's hardware encoder, at the bitrate the phone uses for its own videos
* Auto split: recording only while there is a picture, with a new file after each break longer than a set time
* Recording in the background and with the screen off
* Choice of save folder, Movies/USB Camera Recorder by default

Requires USB host (OTG) support.
